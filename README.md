# 🚌 Bus Seat Booking System

A simple and user-friendly **Bus Seat Booking System** developed using Java. This project allows users to view available seats, select their preferred seats, and confirm their bookings.

## ✨ Features

- 🪑 Display available bus seats
- 🎟️ Select seats for booking
- ✅ Confirm seat bookings
- 🚫 Prevent already booked seats from being selected
- 📋 Display booking details
- 💻 Simple and easy-to-use program

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming
- Arrays
- Loops
- Conditional Statements
- User Input using Scanner

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project in any Java IDE such as VS Code, Eclipse, or IntelliJ IDEA.
3. Compile the Java file.
4. Run `BusSeatBooking.java`.
5. Follow the instructions displayed on the screen.
